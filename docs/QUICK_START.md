
# Quick Start Guide - Ad Revenue System

## For App Administrators

### Access Admin Panel

1. Open the app
2. Go to **Profile** tab (bottom right)
3. Scroll down and tap **"Admin Access"** button
4. Login with:
   - Username: `admin`
   - Password: `admin123`

### View Revenue Dashboard

Once logged in, you'll see:
- 💰 Total revenue earned
- 👁️ Total ad views
- 📅 Today's earnings
- 📊 Ad type breakdown (match vs message)

### Connect Payment Method

1. In admin dashboard, tap **"Connect Debit Card"**
2. Follow the integration guide
3. Set up Stripe account
4. Configure automatic payouts

## For Users

### How Ads Work

**Matching**:
- Tap ❤️ (Like) or ✖️ (Pass) on a profile
- Watch a 5-second ad
- Action completes after ad

**Messaging**:
- Type a message
- Tap send button
- Watch a 5-second ad
- Message sends after ad

### Why Ads?

- App is 100% free to use
- Ads support the platform
- No subscription required
- Fair for everyone

## Revenue Breakdown

### Current Settings

- **$0.05** per ad view
- **5 seconds** per ad
- Required for **every** match/message action

### Example Earnings

**Daily**:
- 100 users × 10 actions = 1,000 ads
- 1,000 ads × $0.05 = **$50/day**

**Monthly**:
- $50/day × 30 days = **$1,500/month**

**Yearly**:
- $1,500/month × 12 = **$18,000/year**
